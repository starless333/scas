Files in. Exact values out.

SCAS programs use one I/O vocabulary across the CLI, desktop IDE, tests, and browser. The host decides where files and input come from; the language keeps the same calls.

UTF-8 text · exact JSON numbers · host-independent runtime

The complete I/O surface

Six builtins cover text, structured data, interactive input, and process arguments. All file paths are strings; I/O failures stop execution with a source diagnostic.

FunctionReturnsPurpose
read_text(path)stringRead an entire UTF-8 text file.
write_text(path, content)nilCreate or replace a UTF-8 text file.
read_csv(path)array of rowsParse comma-separated text; every field remains a string.
read_json(path)SCAS valueConvert JSON arrays, objects, scalars, and exact numbers.
input([prompt])stringRequest one line of user input.
args()array of stringsInspect native process arguments; empty in the browser.
One source, multiple hostsThe evaluator calls a small runtime interface rather than the filesystem directly. The native host supplies real files and standard input; the browser and tests supply an in-memory workspace and queued answers.

Read and write UTF-8 text

read_text returns the complete file as one string. write_text accepts only string content and returns nil after a successful write.

let report = read_text("notes/introduction.txt");
print(report);

let result = factor(x^4 - 1);
let line = format("factorization: {}\n", result);
write_text("build/result.txt", line);

Reading and writing are whole-file operations. SCAS does not currently expose binary files, append mode, directory creation, directory listing, deletion, or streaming handles.

Modules use the same file service

import reads module source through the active host. Imported definitions share the caller's module scope, and the same path is executed only once by an interpreter session.

// lib/geometry.scas
fn circle_area(radius) = pi * radius^2;

// analysis.scas
import "lib/geometry.scas";
print(circle_area(5));

On native hosts, relative import and file paths are relative to the directory from which SCAS was launched—not automatically to the importing source file.

Turn files into SCAS values

JSON preserves numeric notation

read_json parses the complete file and recursively converts it. Integer tokens become arbitrary-size integers; other JSON numbers become arbitrary-precision decimals instead of binary floating-point values.

JSONSCAS
nullnil
true, falseboolean
stringstring
integerarbitrary-size exact integer
decimal or exponent formarbitrary-precision decimal
arrayarray
objectmap with string keys
 
// data.json
// {"experiment":"A-17","samples":[1,2.5],"exact":12345678901234567890}

let data = read_json("data.json");
print(data["experiment"]);  // A-17
print(data["samples"][1]);  // 2.5
print(data["exact"]);       // exact integer

CSV is deliberately literal

read_csv returns an array of row arrays. It supports comma delimiters, quoted fields, commas inside quoted fields, doubled quote escapes, and LF or CRLF line endings. It does not interpret a header, infer types, or require equal row widths.

// measurements.csv
// name,value
// "Ada, A.",42

let rows = read_csv("measurements.csv");
print(rows[0]);     // [name, value]
print(rows[1][0]);  // Ada, A.
print(rows[1][1]);  // 42 (a string)
print(int(rows[1][1]) + 8); // 50
CSV conversionCSV fields remain strings. Convert numeric fields explicitly with int, double, or rational; JSON preserves numeric types automatically.

Interactive input and arguments

input accepts zero arguments or one string prompt. It always returns a string with the native line ending removed.

let name = input("Name: ");
let count = int(input("Count: "));
let rate = double(input("Rate: "));
let share = rational(input("Share (for example 2/3): "));
print(format("Hello, {}", name));

int truncates real numeric values toward zero. double creates an arbitrary-precision decimal at the active precision. rational preserves finite decimals exactly and parses fraction strings such as "2/3". Invalid text and zero denominators are runtime errors with source locations.

In batch automation, prefer files or arguments so the run does not pause for a person. Browser evaluation reports that input is required and lets the interface collect an answer for the run.

Arguments expose the host invocation

let invocation = args();
if invocation != [] {
    print(invocation[0]);
}

Native args() returns every process argument after the executable name. This can include SCAS options and the source path; there is not yet a separate application-argument delimiter. Browser sessions return an empty array.

Errors, limits, and recovery

I/O errors are ordinary runtime errors with source locations. Execution stops rather than returning a partial sentinel value.

FailureTypical diagnosticRecovery
Missing filecould not read … or file '…' was not foundCheck the working directory or upload the browser file.
Invalid virtual pathvirtual paths must be relativeUse a relative path without ...
Write deniedcould not write …Choose a writable directory and check permissions.
Invalid JSONinvalid JSON in '…'Fix the reported JSON line and column.
Invalid CSV quoteunexpected quote or unterminated quoted CSV fieldQuote the whole field and double embedded quotes.
No queued answerinput required: …Answer the prompt or remove interactive input from the batch run.
File too largeJSON or CSV source-size limitReduce or split the file; browser limits are intentionally bounded.

The browser applies its source-size budget to CSV and JSON before parsing. All hosts continue to enforce the active evaluation, recursion, precision, exponent, shift, and number-size limits after values enter the interpreter.

Embed SCAS with a controlled host

Rust callers can implement RuntimeIo and construct an interpreter with that service. This makes file access, prompts, and arguments explicit capabilities instead of global assumptions.

pub trait RuntimeIo {
    fn read_text(&self, path: &str) -> Result<String, IoFailure>;
    fn write_text(&self, path: &str, content: &str) -> Result<(), IoFailure>;
    fn input(&self, prompt: &str) -> Result<String, IoFailure>;
    fn args(&self) -> Vec<String>;
}

MemoryIo is suitable for deterministic tests, sandboxes, and applications that provide their own persistence. It normalizes slash direction, rejects absolute paths and parent traversal, stores files in memory, queues prompt answers, and accepts an explicit argument list.

let io = Rc::new(MemoryIo::new());
io.insert_file("data/input.json", "{\"n\":42}".to_owned())?;
io.queue_input("Ada".to_owned());
io.set_args(vec!["analysis.scas".to_owned()]);
Testing payoffThe same SCAS program can be exercised without touching disk or blocking on standard input. Tests can inspect virtual output files and supply prompt answers deterministically.

Calculus, with explicit boundaries.

Differentiate broadly, integrate known families exactly, evaluate removable limits, build Taylor polynomials, compute finite sums and products, and work across several variables.

Differentiation

derivative(expr, variable) handles constants, sums, products, quotients, general powers, chain rules, elementary and hyperbolic functions, inverse functions, error functions, and assumption-qualified absolute values.

derivative(x^x, x)
derivative(sin(x^2), x)
derivative(erf(3x + 1), x)

Higher derivatives use repeated calls. Unsupported forms remain explicit derivative(...) expressions.

Integration

integral(expr, variable) applies linearity, extracts constant factors, recognizes affine substitutions, and simplifies the result. Supported families include:

  • Polynomial powers and reciprocals of affine expressions.
  • Square/cube roots, exponentials, logarithms, and inverse functions.
  • Trigonometric and hyperbolic functions with affine arguments.
  • sec², csc², sec·tan, and csc·cot.
  • Polynomial × exponential/trigonometric/hyperbolic tabular integration by parts through degree 8.
  • Rational functions whose partial fractions reduce to supported linear and quadratic reciprocal primitives.
  • c/(a*x²+b) for positive rational a,b.
  • Squared sine and cosine via power reduction.
integral(x^2*cos(x), x)
integral((3x + 1) / ((x - 1)*(x + 2)), x)
integral(1 / (x^2 + 1), x)
integral(sin(x)^2, x)
Conservative fallbackWhen a safe primitive is not known, SCAS returns integral(expr, variable) unchanged. It does not invent an antiderivative.

Definite integrals

definite_integral(f, x, a, b) applies the fundamental theorem whenever the symbolic integrator finds a closed primitive. It splits sums and recognizes odd/even symmetry over bounds of the form [-a,a].

definite_integral(x^2, x, -2, 2)
definite_integral(sin(x), x, -pi, pi)

Limits and series

limit(f, x, a) substitutes directly, then uses up to eight L’Hôpital steps for removable 0/0 quotients. A fourth argument accepts "left" or "right". Use "infinity" or "-infinity" for rational-function limits, including divergent results. Finite rational limits use exact polynomial valuations, including high-order one-sided poles; affine absolute-value expressions have directional real limits. Other branch-sensitive limits remain outside the current bounded implementation.

limit(sin(x) / x, x, 0)
limit((x^2 - 1) / (x - 1), x, 1, "left")
limit((3x^2 + 1) / (2x^2 - x), x, "infinity")
series(exp(x), x, 0, 5)
series(1/(x+x^2), x, 0, 5, "O")

series returns the exact degree-n Taylor polynomial. Rational polynomial quotients yield Laurent terms through order 64. An optional fifth argument "O" appends an explicit remainder term. General branch-sensitive expansions remain open.

Sums and products

Finite integer ranges evaluate term by term. Symbolic sums of powers k^p through p=8 use exact Faulhaber formulas; geometric sums also close symbolically. Other symbolic-bound sums/products remain explicit.

sum(k^2, k, 1, 100)
sum(k^3, k, 1, n)
product(k, k, 1, 10)

Differential equations

dsolve([a,b], x) and dsolve([a,b,c], x) return a fundamental basis for homogeneous constant-coefficient equations through second order. dsolve(p,q,x,C) solves y′ + p(x)y = q(x) with the supplied integration constant. dsolve_separable(f,g,x,y,C) returns the implicit equation obtained from dy/dx = f(x)g(y) as a map with left and right primitives. It reports the nonzero-g restriction because constant equilibrium solutions require a separate check.

dsolve([1, -3, 2], x)  // [exp(2x), exp(x)]
dsolve(2, 0, x, C)     // C / exp(2x)
dsolve_separable(x, y, x, y, C) // ln(abs(y)) = x²/2 + C

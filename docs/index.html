What SCAS preserves

Integers and rational numbers remain exact. Decimal evaluation is arbitrary precision. Symbolic expressions are only rewritten when the transformation is safe under known assumptions. Unknown integrals, products, and other unsupported forms remain explicit instead of being guessed.

print(1 / 3 + 1 / 6);        // 1/2
print(sin(pi / 6));          // 1/2
print(sqrt(2));              // sqrt(2)
print(evalf(sqrt(2)));       // requested decimal approximation
print(integral(x^x, x));     // integral(x ^ x, x)

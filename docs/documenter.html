Source that explains its own mathematics.

Document markers live beside executable SCAS. Definitions, prose, equations, derivations, and plots share one evaluation scope and preserve source order.

Three document markers

MarkerPurpose
/// proseParagraph text. Use #{ expression } for evaluated interpolation.
\[ expression \]One display-math line.
\{ statements \}An aligned block containing definitions, expressions, chains, derivations, prose, and plots.

Render source or show a result

Without =>, SCAS renders the source expression. With =>, it evaluates the expression and displays an equation.

\[ (x + 1) / (2x^2) \]
\[ derivative(sin(x), x) => \]

\{
    let A = [1, 2; 3, 4];
    det(A) =>;
    inverse(A) =>;
\}

Every builtin emits structured aligned working when rendered with =>: evaluated arguments, the mathematical rule being applied, and the exact result. Operations with deeper traces add all available intermediate work—for example, row reduction shows every swap, scale, and row replacement, while determinant evaluation shows elimination and the final pivot product.

Prose and interpolation

let radius = 5;
let area = pi * radius^2;
/// A circle of radius #{ radius } has exact area #{ area }.
\[ area => \]

Interpolation is brace-depth and string aware. Failures become document diagnostics rather than corrupting the surrounding prose.

Plots

/// The sine curve on one full period.
plot(sin(x), x, -pi, pi);

\{
    plot(cos(t), t, -pi, pi) =>;
\}

Use plot(expression, lower, upper) for variable x, or provide an explicit variable as the second argument. Document plots render as vector LaTeX pictures.

Large documents in the GUI

The IDE offers a Computer Modern bitmap preview for ordinary documents. Documents too tall for one safe GPU texture—including the complete builtin gallery—automatically use the native scrollable renderer. This is intentional: every row remains visible, responsive, and selectable instead of failing as an oversized bitmap.

Rendering galleryOpen tests/render_all_builtins.scas in the IDE. It contains every registered builtin and is checked for completeness by the test suite.

Export

scas build source.scas output.tex
pdflatex output.tex

The generated document includes AMS math packages, upgreek, booktabs, xcolor, and geometry. The IDE can export both TeX and PDF when pdflatex is installed.

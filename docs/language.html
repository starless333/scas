The SCAS language.

A compact dynamically typed language built around exact values, symbolic expressions, lexical scope, and mathematical notation.

Values and declarations

SCAS values include arbitrary-size integers, reduced rationals, arbitrary-precision decimals, complex numbers, booleans, strings, nil, symbolic expressions, arrays, matrices, functions, and builtins.

let exact = 1 / 7;
let decimal = 1.0 / 7;
let vector = [1, 2, 3];
let matrix = [1, 2; 3, 4];
let message = "exact by default";

Names are Unicode-aware. Constants include pi/π, tau/τ, phi/φ, e, and complex unit i.

Operators

From tightest to loosest: calls/indexing/postfix transpose, exponentiation, unary operators, multiplicative operators, additive operators, shifts, bitwise operations, comparisons, equality, and, then or.

Control flow

let total = 0;
for let k = 1; k <= 10; k += 1 {
    if k % 2 == 0 { total += k; }
}

while total > 0 {
    total -= 1;
    if total == 3 { break; }
}

Only false and nil are falsey. break and continue are valid inside loops; return is valid inside functions.

Functions and closures

fn square(x) = x^2;

fn counter(start) {
    let value = start;
    fn next() { value += 1; return value; }
    return next;
}

let next = counter(10);
print(next()); // 11

Functions capture lexical environments. Expression-bodied functions are concise mathematical definitions; block-bodied functions support statements and explicit return.

Arrays and matrices

let v = [10, 20, 30];
print(v[0]);

let A = [1, 2; 3, 4];
print(A[1, 0]);
print(A' * [5, 6]);

Indexes are zero-based. Matrix rows must be rectangular. Array concatenation uses +; matrix-specific operations validate their dimensions and report runtime errors.

Symbolic evaluation

An unbound name in a mathematical expression becomes symbolic. Builtins operate on that expression and preserve unsupported forms.

let f = x^3 + 2x + sin(x);
print(derivative(f, x));
assume_positive(x);
print(sqrt(x^2)); // x
forget_assumptions();

Comments and statement endings

// begins an ordinary comment. /// begins document prose. Ordinary statements end with semicolons; brace-delimited control flow and function blocks do not need a trailing semicolon.

Errors

Scanner, parser, runtime, and resource-limit errors carry source spans and produce nonzero process statuses in batch mode. Execution stops at the first program error. Documented-result errors appear as visible diagnostics so the rest of a document can remain inspectable.

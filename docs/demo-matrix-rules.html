One value type from rule to result.

The rule syntax creates ordinary nested matrix values. No conversion step separates construction from the existing exact algorithms, so generated matrices can be multiplied, reduced, inverted, differentiated by entry, or passed through limits.

Implicit square size
let H(n) = (...)_(i,j) uses the sole function parameter for both dimensions.
Symbolic entries
(t^(i+j-2))_(i,j,2) fixes the shape while retaining t in every generated entry.
Explicit rectangles
The final two rule arguments specify row and column counts independently.
Entrywise limits
Finite matrix limits preserve shape, while supported matrix-power sequences also flow through trace and determinant.

Read an accessible summary of the generated results

The 3 by 3 Hilbert rule produces rows [1, 1/2, 1/3], [1/2, 1/3, 1/4], and [1/3, 1/4, 1/5]. Its determinant is 1/2160 and its inverse has integer rows [9, -36, 30], [-36, 192, -180], and [30, -180, 180].

The symbolic 2 by 2 rule produces [[1, t], [t, t squared]], whose determinant is zero and whose limit at t = 0 is [[1, 0], [0, 0]]. The rectangular rule produces [[11, 12, 13], [21, 22, 23]]. Powers of the averaging matrix converge to the all-one-half projection, with limiting trace 1 and determinant 0.

Exact matrices, visible working.

Use familiar matrix syntax with exact or symbolic entries, then move from basic operations through decompositions, eigensystems, subspaces, and basis geometry.

Representation and products

let A = [1, 2; 3, 4];
let v = [5, 6];
print(A');
print(A * v);
print(A^3);

let G(n) = (i + j)_(i,j);
print(det(G(2)));

Semicolons separate matrix rows; commas separate entries. Indexed rules use one-based row and column variables; a sole function parameter supplies the square size, and explicit square or rectangular dimensions may follow the index names. Generated matrices retain exact and symbolic entries. A * B and matmul(A,B) are equivalent. Matrix × vector treats the vector as a column. Integer powers use exponentiation by squaring; exponent zero returns identity and negative powers use the exact inverse.

Vector geometry

dot, cross, and norm cover basic vector arithmetic. projection(v,onto) projects one vector onto another; gram_schmidt([vectors]) returns an orthonormal basis and rejects dependent inputs. change_basis(v,[basis_vectors]) returns coordinates in a square basis.

projection([1, 2], [1, 0])
gram_schmidt([[1, 0], [1, 1]])
change_basis([2, 3], [[1, 0], [0, 1]])

Eigenvalues and canonical forms

characteristic_polynomial(A,x) computes det(xI-A) by a division-free cofactor expansion through 6×6. Exact eigenvalues/eigenvectors cover 1×1 and 2×2 matrices and larger triangular matrices where eigenvectors exist. Larger real symmetric matrices use numeric Jacobi; general numeric matrices through 6×6 use residual-checked complex eigenpairs. eigenpairs(A) returns [eigenvalue, eigenvector] records in the same order as eigenvalues(A).

characteristic_polynomial([1, 2; 3, 4], lambda)
eigenvalues([2, 0; 0, 3])
eigenvectors([2, 0; 0, 3])
eigenpairs([2, 0; 0, 3])
eigenpairs([2, 0; 0, 3], "ascending")
svd([3, 0; 0, 4])
jordan_form([2, 1; 0, 2])

jordan_form currently covers through 2×2. matrix_exp evaluates diagonal matrices exactly.

Ordering and SVD

eigenvalues, eigenvectors, and eigenpairs accept an optional "natural", "ascending", or "descending" order. Numeric ordering requires real eigenvalues; paired values and vectors retain the same order. svd(A) returns [U, Sigma, Vt] for real or complex numeric rectangular matrices, with singular values in descending order. For complex matrices, Vt is the conjugate transpose of V. Real 1×1 and 2×2 square cases retain exact arithmetic.

Fundamental subspaces

null_space(A) returns a basis obtained from free variables in RREF. column_space(A) returns original columns corresponding to pivot positions.

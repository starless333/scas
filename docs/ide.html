The mathematical workbench.

The native IDE keeps project navigation, source, live typesetting, diagnostics, output, a persistent REPL, and graphing in one predictable desktop workspace.

Workspace anatomy

SurfaceRole
ExplorerBrowse the current project and open .scas files.
DocumentEdit source with highlighting, completions, diagnostics, snippets, and Unicode math shortcuts.
Document previewSee Computer Modern output or the native structured fallback while editing.
Output / ProblemsInspect program output and source-located diagnostics.
REPLEvaluate incrementally with definitions preserved between submissions.
GraphingManage multiple sampled functions, pan/zoom, probe points, and export SVG.
Status barRead active state, file status, cursor position, and problem count.

Preview behavior

The IDE rebuilds a document in the background after a short editing pause. Invalid in-progress source preserves the last successful preview and displays the current diagnostic. Ordinary documents use latex, dvisvgm, and rsvg-convert when available; zoom rerasterizes from SVG for clear type through 1600%.

Very tall output is routed to the native structured renderer before bitmap creation. This prevents tall render blocks from exceeding DVI or GPU texture dimensions and ensures the builtin gallery remains scrollable.

Themes

Bundled themes live under themes/. A theme supplies semantic UI and syntax roles in TOML, so external themes can change color without changing workspace behavior. Dark Modern is the default; light and dark families are included.

Use scas --help for the exact options supported by the current binary. Batch failures write structured diagnostics to standard error and exit nonzero.

Graph commands

:plot sin(x) draws a terminal graph. :plot svg sin(x) emits SVG in the terminal REPL and draws the curve inline in the IDE; add > graph.svg to save the vector image. The graphing workspace uses cached adaptive sampling, fast interaction previews, full-quality refinement after gestures settle, critical-point detection, and a pin-able probe.

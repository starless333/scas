From source file to exact result.

Build SCAS, run a program, enter the persistent REPL, and turn the same source into a typeset document.

Build

SCAS is a Rust workspace. From the repository root:

cargo build --release --features gui
cargo test --all-targets --all-features

The command-line binary is target/release/scas; the native application is target/release/scas-gui.

Run a program

// hello.scas
let radius = 5;
let area = pi * radius^2;
print(area);
print(evalf(area));
cargo run --bin scas -- hello.scas
cargo run --bin scas -- --precision 50 hello.scas

With no path, SCAS reads standard input. A terminal session opens the line-edited REPL; redirected input executes in batch mode without prompts or colors.

Use the REPL

CommandPurpose
:helpShow REPL commands.
:load path.scasExecute a source file in the current session.
:definitionsInspect current definitions.
:precision NSet decimal precision.
:resetClear the session.
:plot exprDraw a terminal graph.
:plot svg exprEmit SVG markup or save it to a file.

Build a document

cargo run --bin scas -- build notes.scas notes.tex

The output is a complete LaTeX document. Use the desktop IDE for a live preview, or compile the exported file with pdflatex.

Launch the IDE

cargo run --features gui --bin scas-gui -- .

The workspace opens with Explorer, editor, live document preview, output/problems dock, REPL, and graphing workspace. Install latex, dvisvgm, and rsvg-convert for zoom-aware Computer Modern preview; the structured renderer remains available without them. Select any .scas file in the Explorer to edit and preview it.

Plot in the REPL

:plot sin(x)
:plot svg sin(x)
:plot svg sin(x) from -3 to 3 > sine.svg

The SVG command writes vector markup to the terminal unless redirected. Plain :plot sin(x) > sine.svg remains supported.
